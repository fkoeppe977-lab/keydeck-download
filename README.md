# KeyDeck

Deine SoundCloud als Desktop-App für Windows: Feed, Likes, Playlists und Suche wie im Web, dazu Key- und BPM-Analyse für deine eigene Musiksammlung, ein 10-Band-Equalizer, Tracklisten für DJ-Sets und ein Visual Mode.

## ⬇ [KeyDeck herunterladen](https://github.com/fkoeppe977-lab/keydeck-download/releases/latest)

## So installierst du KeyDeck

1. Auf den Link oben klicken und dort unter **„Assets“** auf **`KeyDeck-Setup-….exe`** klicken.
2. Die heruntergeladene Datei doppelklicken.
3. Windows zeigt vielleicht eine blaue Warnung „Der Computer wurde durch Windows geschützt“. Das kommt nur, weil KeyDeck kein gekauftes Zertifikat hat. Auf **„Weitere Informationen“** und dann **„Trotzdem ausführen“** klicken.
4. Durch den Installer klicken. KeyDeck liegt danach auf dem Desktop und im Startmenü.

## Loslegen

- Oben rechts auf **„Mit SoundCloud anmelden“** klicken. Der Browser öffnet die normale SoundCloud-Anmeldung: Dort mit deinem eigenen SoundCloud-Konto einloggen und den Zugriff erlauben. Danach springt KeyDeck von selbst wieder nach vorn.
- Optional: Unter **„Lokale Bibliothek“** einen Ordner mit deiner Musik wählen. KeyDeck erkennt Key und BPM jedes Tracks.
